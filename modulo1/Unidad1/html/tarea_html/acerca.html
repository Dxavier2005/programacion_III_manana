Objetivo

Este proyecto tiene como objetivo facilitar la gestión básica de historias clínicas.

Metadatos y accesibilidad

  • Uso de etiquetas semánticas (header, main, nav).
  • Imágenes con alt.

Definición

La historia clínica es el registro médico-legal del paciente: antecedentes, diagnósticos y tratamiento.
